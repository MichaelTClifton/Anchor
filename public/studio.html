Stream setup

In OBS: Settings → Stream → Service “Custom”, paste the server and key below, then Start Streaming. Use the x264 encoder with AAC audio, and set Keyframe Interval to 2s (Settings → Output) so playback starts quickly.

Anyone with your key can broadcast as you. Regenerating invalidates the old key immediately (and ends a live broadcast, if any).

Replays

When you stop streaming, the broadcast is automatically saved as a video on your channel (streams shorter than a few seconds are discarded). It transcodes in the background like any upload.
